Syarat dan Ketentuan

Dengan menggunakan Shacurity, Anda menyetujui ketentuan berikut:

  • Tujuan edukasi. Shacurity membantu memeriksa domain, tautan, email, dan berkas. Hasilnya bukan jaminan aman atau bukti ancaman.
  • Keputusan pengguna. Anda bertanggung jawab atas keputusan keamanan, transaksi, unduhan, dan tindakan lanjutan setelah melihat hasil.
  • Privasi. Cek Domain & Link mengirim host/domain ke DNS publik, RDAP, SecurityHeaders.com, dan CertSpotter untuk mengambil hasil online. URL lengkap, alamat email, dan file tidak dikirim oleh fitur tersebut; email dan file diperiksa lokal.
  • Data sementara. Situs dapat menyimpan preferensi tema dan status persetujuan ini pada browser Anda melalui penyimpanan lokal.
  • Tidak ada jaminan. Informasi dan hasil dapat berubah, tidak lengkap, atau mengandung hasil positif maupun negatif yang keliru.

Jangan unggah data rahasia atau berkas yang tidak Anda berhak periksanya. Gunakan hasil sebagai salah satu faktor penilaian dan selalu verifikasi melalui sumber resmi.

        FAQ
        
          
        Pertanyaan yang Sering Diajukan
        
        
        

        
        
          
        
            
            
        
              Bagian ICANN dikelola oleh registri domain resmi (seperti .com, .ac.id, .co.uk), sedangkan bagian PRIVATE diajukan oleh penyedia layanan/platform (seperti github.io, pages.dev, vercel.app, netlify.app) agar setiap proyek pengguna dianggap sebagai domain utama terpisah. Karena siapa saja dapat membuat akun dan mendaftarkan nama di bawah akhiran PRIVATE, alamat berakhiran PRIVATE perlu diverifikasi sumbernya.
            
        
          
        

          
        
            
            
        
              Pada standar URL, bagian sebelum tanda @ dianggap sebagai info otentikasi pengguna, sedangkan alamat server tujuan sebenarnya berada setelah tanda @. Pada contoh http://umm.ac.id@verifikasi.xyz, browser akan mengabaikan umm.ac.id dan membuka verifikasi.xyz.
            
        
          
        

          
        
            
            
        
              File dan email diperiksa di perangkat Anda. Cek Domain & Link mengirim host/domain ke DNS publik, RDAP, SecurityHeaders.com, dan CertSpotter; aplikasi tidak membuka situs tujuan. URL path, email, dan file tidak dikirim.
            
        
          
        

          
        
            
            
        
              Tidak. Domain memakai heuristik lokal serta data DNS/RDAP/HTTP/sertifikat yang tersedia; email memakai pola lokal terbatas; file diperiksa melalui struktur, pola uji EICAR, dan SHA-256. Ini bukan pemindaian antivirus atau jaminan bebas ancaman.
            
        
          
        

          
        
            
            
        
              PSL membantu mengenali batas akhiran publik—misalnya .co.uk—agar alat dapat membedakan domain utama dari subdomain. Aplikasi memakai daftar lokal ringkas; akhiran yang tidak dikenal menggunakan fallback dan hasilnya perlu diverifikasi.
